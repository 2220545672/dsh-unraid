This page brings back an authorization code your browser could not deliver. Back to DSH →

这个页面负责把浏览器没能送回的授权码带回来。返回 DSH →

  1. The sign-in tab you just opened ends on an error like “This site can’t be reached” for 127.0.0.1. That is expected: the platform only lets the login come back to a loopback address, which your browser cannot reach on this server.
  2. Go to that tab, select the whole address bar (Ctrl+L), copy it (Ctrl+C).
  3. Paste it below and continue. The last step happens here, on this server, and the sign-in page you started from turns green by itself.
  1. 刚才打开的登录标签页最后会停在一个 127.0.0.1 的“无法访问此网站”错误页。这是预期的：平台只允许登录结果回到回环地址，而你手上的浏览器访问不到服务器上的回环地址。
  2. 切到那个标签页，选中整个地址栏（Ctrl+L），复制（Ctrl+C）。
  3. 粘贴到下面并继续。最后一步在这台服务器上完成，原来那个登录窗口会自己变成已登录。

Do it within ~10 minutes, and against the same container. The authorization code belongs to the sign-in you just started: it expires with it, and recreating the container throws it away. If you are too late, nothing is broken — just start the sign-in again.

请在约 10 分钟内、并且针对同一个容器完成。授权码属于你刚发起的那次登录： 它会随那次登录一起过期，容器重建也会把它作废。过期不算故障——重新点一次登录即可。

What this does with the code这个页面拿授权码做什么

It sends code and state from the address you pasted to this same server, on the path DeepSeek Harness already uses for its own callback. The server checks the one-time state it created for the sign-in you started, exchanges the code with the PKCE verifier it kept in memory, and stores the resulting credential. Nothing is sent anywhere else, the code is single-use, and it expires with the attempt. The request is made from this page and its answer is shown here, so a failure explains itself instead of leaving you on an empty 404 page.

它只把你粘贴的地址里的 code 和 state 发到本服务器上 DeepSeek Harness 自己的回调路径。服务器会校验它为本次登录生成的一次性 state，用在内存里的 PKCE verifier 换取凭据并保存。除此之外不发给任何地方；授权码一次性有效，且随本次登录尝试一起过期。请求由本页面发出、结果也显示在这里，所以失败时你会看到原因，而不是一个空白的 404 页面。

Nothing to paste? Start over in the DSH tab, or use an API key instead.

没有可粘贴的地址？回到 DSH 标签页重新点一次登录，或改用 API Key。
